### 🌀 LiDAR Interactive Wall

<div align="center">

<!-- NOTE: this GIF renders once you push the `lidar-interactive-wall`

     the two URLs below. -->
<a href="https://github.com/MDDANISH2001/lidar-interactive-wall">
<img src="https://raw.githubusercontent.com/MDDANISH2001/lidar-interactive-wall/main/docs/demo-water.gif" alt="Drawing a light barrier that catches simulated falling water" width="70%"/>
</a>

</div>

Turned a **4.5-meter projection wall into a giant multi-touch playground** using a spinning
LiDAR — no touchscreen, no camera. A Python pipeline converts raw laser echoes into calibrated
multi-touch events (~1.5 ms WebSocket latency); the browser renders **million-particle GPU
simulations**: a silk-strand logo that scatters and re-forms, a real 2D fluid you sculpt by
drawing light barriers, and arcade games kids play with their whole body.

**Highlights** · custom UDP LiDAR driver · OpenCV homography calibration · ping-pong FBO
particle physics in GLSL · SPH fluid simulation · 60 fps on a wall-sized display

[![Repo](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/MDDANISH2001/lidar-interactive-wall)
